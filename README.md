# 🧹 CleanCodeTool — Universal Dark Edition (Win32 GUI / C++)

[RU] Ультра-быстрая и всеядная утилита в тёмном Flat-дизайне для полной очистки любых файлов от пустых строк, лишних пробелов, табов и комментариев.

## ✨ Features / Особенности
- **🎨 Modern Dark UI:** Eye-friendly dark gaming/coder theme built on raw Win32 painting. / **Стильный Dark-дизайн:** темная тема, написанная на чистом WinAPI, идеально смотрится на рабочем столе и не режет глаза ночью.
- **🖱 Drag & Drop Support:** Drop your script or text file directly from File Explorer into the app. / **Поддержка Drag & Drop:** просто перетащите файл из проводника мышкой прямо в окно программы.
- **🧠 Auto Language Selection:** Detects the language by file extension (`.py`, `.cpp`, `.rs`, `.js`, `.go`) or select any other text file. / **Умное определение:** автоматически угадывает язык программирования по расширению файла.
- **⚙️ 3 Processing Modes:** Remove comments only, empty lines only, or wipe both at once. / **3 режима работы:** удалить только комментарии, только пустые строки или всё вместе.
- **🛡 Safe Strings Protection:** Core parser never touches comments inside active text blocks or strings. / **Защита строк:** интеллектуальный парсер никогда не удалит комментарии, находящиеся внутри текстовых кавычек.
- **🪶 Ultra Lightweight:** Standalone `.exe` takes less than 200 KB and opens instantly. / **Ультра-легкий вес:** весит менее 200 КБ, имеет 0% нагрузки на CPU и собран со статической линковкой (`/MT`).

## 🛠 Supported Formats / Поддерживаемые форматы
- Python (`#` style comments)
- C++ / C / Rust / JavaScript / TypeScript / Go (`//` and `/* */` style comments)
- **Universal Mode:** Absolutely ANY text format (`.txt`, `.html`, `.json`, `.cfg`, `.srt`, etc.) for empty lines removal. / **Универсальный режим:** удаление пустого «воздуха» из файлов любых форматов.
